- 반전 면(`.invert`, `.cal .hl`, `li.real`, `.onepage .head`) 안에서는 `--accent`, `--soothing`, `--intensive`, `--estimate`, `--on-season`이 자동으로 `-inv` 값으로 바뀐다. 기존 초안에서 검정 카드 안의 `(추정)` 글자가 어두운 오렌지라 대비가 낮던 문제를 이것으로 고쳤다.

### 컴포넌트별 색
- 표지: 맨 위 8px 시즌 스트립(왼쪽 수딩, 오른쪽 인텐시브), 듀오 태그, h1 둘째 줄 밑줄(수딩→인텐시브 그라데이션). 표지 핵심 숫자 카드는 무신사 GNB처럼 검정 반전 + 위쪽 4px 수딩 선.
- 페르소나: 카드 위쪽 6px 선과 태그. 봄 러너=수딩, 겨울 산행러=인텐시브, 환절기 민감러=반반(듀오).
- 듀오 비교: 각 칸에 시즌 틴트 배경 + 위쪽 6px 시즌 선, 라인명 h3를 시즌 색으로.
- 캘린더: 위쪽 6px 시즌 바가 타임라인 역할(준비=회색, 3~8월=수딩, 9~12월=인텐시브). 860px 이하는 왼쪽 세로 바. 강조 월은 검정 반전, 칩은 시즌 색.
- 막대그래프: 환절기 민감러=수딩→인텐시브 그라데이션(듀오), 봄 러너=수딩, 겨울 산행러=인텐시브, 1회 구매만=`--muted`.
- 가정 박스·(추정): `--estimate` 점선 테두리와 라벨.

## 4. 모션 목록
모든 모션은 점진적 향상이다. JS가 없거나 IntersectionObserver가 없으면 모든 내용이 처음부터 끝 상태로 보인다. 숨김 초기 상태는 JS가 `<html>`에 `.motion` 클래스를 붙였을 때만 적용된다.

| 대상 | 트리거 | 길이 | 의도 |
|---|---|---|---|
| 표지 시즌 스트립 | 페이지 로드 (CSS) | 수딩 0.8s(0.15s 지연) → 인텐시브 0.8s(0.95s 지연) | 첫 화면에서 '수딩 다음 인텐시브' 순서를 보여 준다 |
| 표지 듀오 태그 | 페이지 로드 (CSS) | 각 0.5s, '봄엔 수딩' 0.2s → '겨울엔 인텐시브' 1.0s | 같은 순서를 카피로 반복 |
| 표지 h1 밑줄 | 페이지 로드 (CSS) | 2.2s(0.3s 지연): 수딩색으로 그어진 뒤 인텐시브색으로 넘어감 | "크림도 바꾸세요" = 시즌 전환 |
| 스크롤 등장 (리드, 핵심 문장, 카드, 듀오 칸, 표, 막대 묶음, 가정 박스, 5WHY 항목, 한 장 요약, 블록 제목) | 요소가 화면의 약 15% 들어올 때 | 0.6s, 위로 18px + 페이드, 형제끼리 80ms 간격(최대 5단계) | 읽는 순서를 따라 정보가 차례로 놓인다 |

| 막대그래프 채움 + 금액 카운트업 | 막대 묶음이 화면에 들어올 때 | 1.0s, 막대끼리 120ms 간격 | 페르소나별 가치 차이를 길이로 체감 |

카운트업 제외(원문 유지): `5명 중 1명`, `2.44 : 1`, `19.7% · 9.2%`, `1.5~2배`, 문장 속 숫자(2,188, 24,800원 → 33,120원 등). 숫자 하나에 접두 `+`·접미 단위만 붙은 문구만 센다(예: `83.1%`, `+262%`, `262명`, `9.8일분`, `59,467원`). 소수 자릿수와 천 단위 쉼표는 원문 형식을 따른다.

쓰지 않은 것(1차 기준): 패럴랙스, 마퀴, 무한 반복 애니메이션, 스크롤 진행 바. 2차에서 스크롤 진행 바와 표지 커서 패럴랙스(소폭)를 추가했다(7장).

## 5. reduced-motion·접근성 처리
- `prefers-reduced-motion: reduce`이면 JS가 아무것도 하지 않고 바로 끝난다(숨김·카운트업·막대 0 시작 모두 없음). CSS도 표지 애니메이션을 `no-preference` 조건 안에만 두고, `reduce`일 때 모든 animation·transition을 끄며 `scroll-behavior`를 `auto`로 바꾼다.
- 표지 애니메이션의 끝 상태는 정적 디자인과 같다(`animation-fill-mode: both`).
- 빠른 스크롤로 관찰 프레임을 놓친 요소는 스크롤 이벤트 보정으로 곧바로 표시한다. 인쇄 시(`beforeprint`, `@media print`) 모든 요소를 끝 상태로 바꾼다.
- 링크 포커스에 2px 수딩 아웃라인, 각주로 이동하면 해당 출처 줄을 강조(`:target`).

### 8-6. 인쇄 (#034)
- `@media print`에서 라이트 토큰을 강제한다(OS 다크 모드여도 흰 종이에 검정 글자).
- 반전 면(검정 카드, 캘린더 강조 월, REAL WHY, 한 장 요약 머리)은 흰 바탕 + 2px 검정 테두리 + 검정 글자로 바꾼다.
- 시즌 태그·칩·배지·막대는 `print-color-adjust: exact`. 내비·진행 바·스크롤 안내는 숨김. 카드·표 행·결재 띠·요약은 `break-inside: avoid`.
