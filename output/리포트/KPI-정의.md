## 핵심 결론 3줄
1. **무신사가 가장 듣고 싶은 지표는 '반복 구매'다.** 뷰티 첫 구매 고객의 83.1%가 패션 고객이므로, 무신사의 다음 과제는 이들을 뷰티 재구매 고객으로 만드는 것이다. 북극성 지표로 **'제로이드 2회 이상 구매 고객 수'**를 제안한다(재구매 표시 비율: 수딩 19.7%, 인텐시브 9.2%, 올리브영 리뷰 기준).
2. **듀오 구조는 KPI 두 개를 동시에 움직인다.** 듀오 세트 구매 비중은 객단가를(듀오 정가 합 6.2만~7.8만 원, 무신사 홍대 오픈 3일 객단가 약 11만 원), 수딩→인텐시브 계절 전환율은 재구매율을 끌어올린다. 둘 다 별도 KPI로 둔다.
3. **1년차 목표는 절대 거래액이 아니라 '비율·순위·성장률'로 건다(추정).** 북극성: 12개월 내 첫 구매 고객의 25% 이상이 2회 이상 구매. 월 거래액 성장률 +4.5% 이상(경쟁 더마 연 +69%의 월 환산), 더모 코스메틱 순위 6개월 Top 5·12개월 Top 3, 팝업 후 4주 온라인 일평균 거래액 +35% 이상. 모두 [미확인] 가정에 기대므로 사용자 확정이 필요하다.

## 0. KPI 체계
```
북극성: 제로이드 2회 이상 구매 고객 수 (무신사 온·오프라인)
 ├─ 유입: M1 신규 고객 유입 · M6 오프라인 방문 · Z4 브랜드 인지
 ├─ 전환: M2 거래액 · M6 팝업 구매 전환 · Z6 체험→구매
 ├─ 확장: M3 객단가 · M8 듀오 세트 비중
 ├─ 유지: M4 재구매율 · Z3 계절 전환율
 └─ 카테고리: M5 더마 카테고리 기여 · M7 리뷰 수·평점
```
- 북극성 선정 이유: 무신사의 5WHY(교차 구매 고객 → 뷰티 반복 구매)와 제로이드 리뷰의 강점(재구매·계절 재구매)이 만나는 지점이다. [확인됨: decisions.md KPI 방식]

### 북극성 지표: 제로이드 2회 이상 구매 고객 수 (무신사 온·오프라인)
| 항목 | 내용 |
|---|---|
| 정의 | 무신사 온라인·오프라인(매장·팝업)에서 제로이드를 2회 이상(서로 다른 주문) 구매한 고객 수. 라인 무관 |
| 산식 | 누적 2회 이상 구매 고객 수(월말 기준). 보조: 첫 구매 고객 대비 비율 = 2회 이상 구매 고객 ÷ 같은 코호트 첫 구매 고객 |
| 측정 방법 | 무신사 구매자 단위 데이터(온·오프라인 통합 회원 ID). 데이터 공유 요청 항목 |
| 측정 시점 | 월별 누적, 판정 T4·T6 |
| **목표치** | **12개월 내 첫 구매 고객의 25% 이상(도전 35%), 월별 누적 고객 수 매월 증가** (추정) [미확인] |
| 근거 | 첫 구매 1,000명 코호트 추정 262명(26.2%) = Σ 페르소나 비중 × 재구매 확률(봄 러너 30%·겨울 산행러 15%·환절기 민감러 30%) (페르소나-재구매-수익.md 3장) |
| So what | 재구매가 첫 구매 거래액에 약 35%를 더한다(추정). 절대 고객 수 목표 대신 '비율 + 매월 증가'로 걸어 신규 입점의 불확실성을 피한다 |

## 1. 무신사 관점 KPI

### M1. 신규 고객 유입
| 항목 | 내용 |
|---|---|
| 정의 | 제로이드 상품으로 무신사 뷰티 첫 구매를 한 고객 수. 하위 지표: (a) 무신사 신규 가입 후 첫 구매 고객, (b) 패션 등 기존 고객의 뷰티 첫 구매(교차 구매), (c) 러닝·아웃도어 구매 이력 고객의 뷰티 첫 구매 |
| 산식 | 신규 유입 고객 수 = 기간 중 제로이드 구매자 중 '무신사 뷰티 구매 이력 없음' 고객 수. 신규 유입 비율 = 신규 유입 고객 ÷ 제로이드 구매 고객 |
| 측정 방법 | 무신사 브랜드 파트너 데이터(구매자 이력 플래그). 제공 범위는 [미확인] → 입점 협의 때 데이터 공유 항목으로 요청 |
| 측정 시점 | T1, T3, T4, T6 |
| 목표치 | **제로이드 첫 구매자 중 무신사 뷰티 첫 구매 고객 30% 이상**(추정, 범위 20~40%) [미확인]. 교차 구매 비율은 **무신사 뷰티 평균 83.1% 이상**. 스포츠·아웃도어 구매 이력 비율은 무신사 뷰티 첫 구매자 평균 대비 1.2배 이상(평균값은 데이터 공유 요청) [미확인]. 신규 구매자 **절대 수 목표는 두지 않고 월별 증가**로 본다 |
| 기준값(벤치마크) | ① 무신사 뷰티 첫 구매 고객의 83.1%가 다른 카테고리 기존 고객(2026년 1~8월, 한국경제 2026-09-16) → 뷰티 첫 구매 중 비교차 고객 16.9%(계산: 100−83.1). ② 무신사 회원 약 1,640만 명(누적, 한국경제 2026-09-16) |
| So what | 83.1%를 기준으로 제로이드 첫 구매자 중 교차 구매 비중이 더 높으면 '패션 고객을 뷰티로 넘긴 브랜드', (c) 비중이 높으면 '러닝·아웃도어 고객을 뷰티로 넘긴 브랜드'라고 보고할 수 있다 |

### M2. 거래액(GMV)
| 항목 | 내용 |
|---|---|
| 정의 | 무신사 온라인 + 오프라인(매장·팝업)에서 발생한 제로이드 거래액. 라인별(수딩·인텐시브·핌프로브)·채널별로 나눠 본다 |
| 산식 | 거래액 = 방문자 수 × 구매 전환율 × 객단가. 성장률 = (당기 − 비교기) ÷ 비교기 |
| 측정 방법 | 무신사 파트너 매출 리포트(주간), 팝업 POS |
| 측정 시점 | 주간 모니터링, T1·T3·T4·T6 판정 |
| 목표치 | **거래액 절대 목표 없음.** 1년차는 **월 거래액 성장률(전월 대비) 2027.6~2028.2 평균 +4.5% 이상, 도전 +9.4%**(추정) [미확인]. 산식: (1+경쟁 더마 연 성장률)^(1/12)−1 → 셀퓨전씨 +69% = 월 4.5%, 에스트라 +193% = 월 9.4%. 행사 기간 거래액 증가율(행사 일평균 ÷ 직전 4주 일평균) **+150% 이상**(무뷰페 2026 직전 기간 대비 +150%) |
| 기준값 | ① 무신사 더마 브랜드 2026년 1~8월 거래액 성장: 에스트라 +193%, 일리윤 +289%, 코스알엑스 +72%, 셀퓨전씨 +69%(뉴스토마토 2026-09-30) ② 무신사 뷰티 2025년 +50% 이상(바이라인네트워크 2026-01-27) ③ 무뷰페 2026 온라인 거래액 전년 대비 +246%(바이라인네트워크 2026-08-25) ④ 제로이드 올리브영 리뷰 규모: 수딩·인텐시브 확인 SKU 약 3.9만 건(수요 규모의 간접 지표) |
| 공백 | 무신사 뷰티 거래액 절대값, 더마 카테고리 거래액, 제로이드 올리브영 매출 모두 비공개 → 첫해는 절대값 목표보다 **'월별 성장률'과 '더마 카테고리 내 순위'** 목표가 현실적 [미확인: 추천] |
| So what | 신규 입점이라 전년 비교가 없다. 성장률 벤치마크는 입점 2년차부터 쓰고, 1년차는 월별 추세와 카테고리 순위로 판정한다 |

### M3. 객단가(AOV)
| 항목 | 내용 |
|---|---|
| 정의 | 제로이드 상품을 포함한 주문의 주문당 제로이드 결제액. 보조: 제로이드 포함 주문의 전체 결제액(타 브랜드 동반 구매 효과) |
| 산식 | 객단가 = 제로이드 거래액 ÷ 제로이드 포함 주문 수 |
| 측정 방법 | 무신사 파트너 데이터, 팝업 POS |
| 측정 시점 | T1, T2, T4 |
| 목표치 | **33,000원 이상**(단품만 24,800원 대비 +34%, 추정) [미확인]. 산식: 단품 31,000×0.8×0.7 + 듀오 62,000×0.8×0.2 + 기획세트 평균 73,000×0.8×0.1. 가정: 할인 20%, 듀오 비중 20%, 기획세트 10% |
| 기준값 | ① 듀오 정가 합: 단품 80ml 62,000원(수딩 크림 30,000 + 인텐시브 크림 32,000), 올리브영 기획 78,000원(38,000 + 40,000) — 올리브영 정가 2026-10-30 ② 단품 정가 범위 30,000~58,000원(리뷰-정량분석.md 2-1) ③ 무신사 뷰티 홍대 **오픈 3일** 객단가 약 11만 원(한국경제 2026-09-16, 오픈 효과 포함) ④ 무신사 판매가·할인율 [미확인] |
| So what | 단품만 팔리면 객단가는 3만 원대, 듀오가 팔리면 6만~8만 원대로 약 2배가 된다. 객단가 목표는 M8(듀오 비중)과 함께 정해야 한다 |

### M4. 재구매율
| 항목 | 내용 |
|---|---|
| 정의 | 제로이드 첫 구매 고객 중 일정 기간 안에 제로이드를 다시 산 고객 비율. 라인 무관 |
| 산식 | 재구매율(N일) = 첫 구매 후 N일 안에 2회 이상 구매한 고객 ÷ 같은 기간 첫 구매 고객. N = 90일, 180일 |
| 측정 방법 | 무신사 파트너 데이터(구매자 단위 코호트). 코호트는 월별 첫 구매 고객 |
| 측정 시점 | 90일: 3월 코호트 → 2027년 6월 말(T3). 180일: 3월 코호트 → 9월 말(T4). 연간: T6 |
| 목표치 | **180일 재구매율 15%, 12개월 25%**(추정, 도전 35%) [미확인]. 90일은 크림 사용 주기(약 80일)·로션(약 107일) 직후라 참고 지표로만 본다. 북극성과 같은 코호트로 잰다 |
| 기준값 | ① 올리브영 리뷰 **재구매 표시 비율**: 수딩 19.7%, 인텐시브 9.2%(크림·로션 각 600개 표본), 전체 9개 SKU 9.6%(450개 표본) — 리뷰-정량분석.md 4절 ② 무신사 뷰티 재구매율 비공개 [미확인] ③ 크림 80ml 사용 기간(재구매 주기) [미확인] |
| 주의 | 재구매 표시 비율은 '리뷰 쓴 사람 중 재구매자 비중'이라 실제 재구매율과 다르다. 목표 산정 때 그대로 쓰면 안 되고, 상대 비교(수딩이 인텐시브의 약 2배)로만 쓴다 |
| So what | 재구매 신호가 강한 수딩을 봄 히어로로 세우면, 3월 코호트의 180일 재구매(9월)가 가을 인텐시브 전환과 겹쳐 재구매율을 끌어올릴 수 있다 |

### M5. 더마 카테고리 성장 기여
| 항목 | 내용 |
|---|---|
| 정의 | 무신사 더모 코스메틱 카테고리 성장에 제로이드가 기여한 정도 |
| 산식 | ① 카테고리 내 거래액 비중 = 제로이드 거래액 ÷ 더마 카테고리 거래액 ② 성장 기여도 = 제로이드 거래액 증가분 ÷ 카테고리 거래액 증가분 ③ 카테고리 내 브랜드 순위(거래액·판매량·후기 수) |
| 측정 방법 | 무신사 카테고리 데이터(MD 제공), 공개 지표로는 카테고리 랭킹 순위 |
| 측정 시점 | T1, T4, T6 |
| 목표치 | **더모 코스메틱 카테고리 브랜드 순위 6개월(T4) Top 5, 12개월(T6) Top 3**(17개 브랜드 중, 추정) [미확인]. 거래액 비중·성장 기여도(①②)는 카테고리 거래액이 비공개라 목표 없이 MD 공유값으로 사후 계산 |
| 기준값 | ① 국내 더마 시장 연평균 14.5%, 더마 스킨케어 15.7% vs 스킨케어 전체 2.1%(유로모니터, 이데일리 2026-09-02) ② 무신사 더마 카테고리 브랜드 16개·상품 698개(2026-10-30 조회) → 제로이드 입점 시 브랜드 수 +6%(계산) ③ 국내 스킨케어 중 더마 비중 17.1% |
| So what | 카테고리 성장률이 시장 성장률(14.5%)보다 높아지는 데 제로이드가 얼마나 기여했는지가 MD의 내부 보고 포인트다 |

### M6. 오프라인 방문·매출 (팝업·매장)
| 항목 | 내용 |
|---|---|
| 정의 | 4~5월 팝업과 무신사 뷰티 상설 매장(홍대·성수)에서의 방문, 체험, 구매 |
| 산식 | ① 방문객 수(카운터 집계) ② 구매 전환율 = 구매 영수증 수 ÷ 방문객 수 ③ 팝업 매출 = 구매 건수 × 객단가 ④ **오프라인 → 온라인 파급** = 팝업 종료 후 4주 온라인 일평균 거래액 ÷ 팝업 전 4주 온라인 일평균 거래액 − 1 ⑤ 매장 재방문(샘플 수령 고객의 쿠폰 사용률) |
| 측정 방법 | 출입 카운터, 팝업 POS, 무신사 앱 쿠폰·QR 사용 데이터 |
| 측정 시점 | T2(일 단위), T3 |
| 목표치 | **팝업 후 4주 온라인 일평균 거래액 상승률 +35% 이상**(도전 +50%). 기준값: 성수 메가스토어 입점 브랜드 3주 +35%(4주로 측정, 비교용 3주 값 병기). 보조(목표 아님, 규모 추정): 방문객 4,200명(14일×300명), 현장 구매 전환율 15%, 체험 참여율 50%, 체험자 4주 내 온라인 구매 10% [모두 미확인] |
| 기준값 | ① 성수 메가스토어 입점 약 500개 브랜드의 온라인 일평균 거래액 입점 후 3주간 약 **+35%**(한국경제 2026-09-16) ② 무뷰페 in 성수 2026: 4일 3만 1천 명, 부스 64개 → 부스당 평균 약 480명(계산, 상한)(바이라인네트워크 2026-08-25) ③ 무신사 뷰티 홍대 오픈 3일 매출 2억 5천만 원, 객단가 약 11만 원(한국경제 2026-09-16) ④ 올리브영 리뷰 중 매장구매 28%(리뷰-정량분석.md 6절) ⑤ 무신사 2025년 오프라인 방문객 3,200만 명 이상 ⑥ 팝업 비용·운영 조건은 '협의'(decisions.md) |
| So what | ④가 높을수록 제로이드는 '발라 보고 사는' 브랜드다. 팝업 성과는 현장 매출보다 ④(+35% 대비) 같은 **온라인 파급**으로 평가하는 것이 MD에게 설득력이 크다 |

## 4. 목표치 산정 산식 (숫자는 기대효과-추정.md)
- 온라인 거래액 = 상품 상세 방문자 × 구매 전환율 × 객단가
- 객단가 = 단품 평균가 × (1 − 듀오 비중) + 듀오가 × 듀오 비중
- 팝업 매출 = 방문객 × 구매 전환율 × 팝업 객단가
- 팝업 파급 거래액 = 팝업 전 4주 온라인 일평균 거래액 × 파급률(기준 +35%) × 28일
- 연간 재구매 고객 = 첫 구매 고객 × 180일 재구매율 + 수딩 구매자 × 계절 전환율
