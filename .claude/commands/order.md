## 사용자의 오더
$ARGUMENTS

## 팀원
| 에이전트 | 담당 | 산출물 위치 |
|---|---|---|
| `research-team` | 제품·브랜드 컨셉 분석, 리뷰·리뷰어 분석, 시장·경쟁사·무신사뷰티 조사 | `research/` |
| `content-planner` | 캠페인 컨셉, 타깃·페르소나, 카피, 채널 운영안 | `output/기획/` |
| `data-analyst` | KPI 정의, 성과·기대효과 분석, 정량 분석, 리포트 | `output/리포트/` |
| `design-team` | 산출물 전체 디자인: 색상 팔레트, 타이포, 레이아웃, 모션 그래픽, 반응형 | `output/최종 디자인/` |

## 진행 절차

### ① 업무 분해
오더를 아래 업무 유형으로 나누고, 근거 조사가 필요하면 리서치 업무를 따로 뽑는다.
- **기획**: 컨셉, 타깃, 페르소나, 제안 구조 → `content-planner`
- **카피**: 헤드라인, 컨셉 문구, 상세페이지·팝업 카피 → `content-planner`
- **채널운영**: 무신사 몰 입점 구성, 프로모션 캘린더, 오프라인 매장·팝업 운영 → `content-planner` (KPI가 걸린 부분은 `data-analyst`와 함께)
- **분석**: KPI, 기대효과, 리뷰·시장 데이터의 정량 분석, 리포트 → `data-analyst`
- **디자인**: 팔레트, 레이아웃, 모션 그래픽, 최종 HTML 디자인 → `design-team`
- (리서치: 사실·근거 수집 → `research-team`)

오더에 해당하지 않는 유형은 "해당 없음"으로 표시한다. 이미 `research/`나 `output/`에 쓸 수 있는 결과가 있으면 확인해서 중복 작업을 피한다.

### ② 실행 전 브리핑 (반드시 먼저 제시)
팀원에게 일을 맡기기 전에 다음 형식으로 브리핑하고 **멈춘다.**

```
## 브리핑
### 업무 분해
| 업무 유형 | 세부 업무 | 담당 |
### 진행 순서
- 1단계 (동시 진행): ...
- 2단계 (1단계 결과 필요, 순차): ...
### 예상 산출물
| 담당 | 파일 경로 | 내용 |
### 결정이 필요한 사항
(③의 선택지)
```

- 순서를 정할 때 의존 관계를 따진다. 서로의 결과가 필요 없는 업무는 같은 단계에 묶어 동시에 진행한다. 다른 업무의 결과가 필요한 업무만 다음 단계로 미룬다. 예: 리서치 결과가 필요한 컨셉 기획은 리서치 뒤에, 기획의 성공 지표가 필요한 KPI 정의는 기획 뒤에 둔다.

### ③ 방향성 갈림길
컨셉 방향, 히어로 라인, 타깃 우선순위, 범위(온라인만 또는 오프라인 포함) 등 결과를 크게 바꾸는 갈림길이 있으면 AskUserQuestion으로 선택지를 제시하고 사용자의 결정을 받는다. 추천안을 첫 번째 선택지로 두고 이유를 적는다. 갈림길이 없으면 "결정 필요 사항 없음"이라고 적는다.

### ④ 승인 후 업무 하달
- 사용자가 승인하기 전에는 팀원 에이전트를 호출하지 않는다.
- 승인을 받으면 Agent 도구로 팀원에게 업무를 맡긴다. `subagent_type`에 에이전트 이름을 쓴다.
- **같은 단계의 독립 업무는 반드시 한 메시지 안에서 여러 Agent 호출로 동시에 보낸다.** 하나씩 기다리며 보내지 않는다.
- 각 지시문에는 다음을 담는다: 오더의 맥락, 맡길 세부 업무, 사용자가 결정한 방향(③), 읽어야 할 선행 산출물 경로, 저장할 파일 경로, 보고 형식.
- 다음 단계는 앞 단계 결과를 받은 뒤 그 결과 파일 경로를 지시문에 넣어 보낸다.
- 팀원이 올린 "사용자 확인 필요" 항목이 다음 단계 진행을 막으면, 다음 단계로 넘어가기 전에 사용자에게 묻는다. 막지 않으면 모아 두었다가 최종 보고에서 묻는다. 확정된 내용은 `research/decisions.md`에 기록한다.

### ⑤ 최종 보고
모든 팀원이 끝나면 결과를 취합해 보고한다. 팀원의 보고를 그대로 믿지 말고 산출물 파일이 실제로 있는지, 기획안에 목표·타깃·핵심 메시지·일정·성공 지표가 다 있는지, 리포트의 숫자에 so what이 붙어 있는지 확인한다.

```
## 최종 보고
### 한 줄 결론
### 팀원별 결과
- 리서치 팀: 핵심 발견 / 파일 경로
- 콘텐츠 기획자: 핵심 기획 / 파일 경로
- 데이터 분석가: 핵심 숫자와 so what / 파일 경로
### 산출물 파일 목록
### 사용자 확인 필요 사항
### 다음 단계 제안
```
